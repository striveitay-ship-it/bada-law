# אדיט: האח הקטן

אדיט אנכי (1080×1920, ‏60fps, ‏19.7 שניות) על הסאונד "Montagem Zora (Slowed)", בסגנון של האדיט שנשלח כרפרנס.

**הסרטון עצמו לא נמצא בריפו.** הריפו ציבורי והקליפים הם של ילד, ולכן גם המקור וגם התוצאה נשארים מחוץ ל-git (`.gitignore`). כאן נמצא רק הקוד שבונה את הסרטון.

## הסגנון (לפי הרפרנס)
- פלאש נגטיב (4 פריימים) על ה-"3" של כל תיבה, בדיוק כמו ברפרנס, ומיד אחריו קאט.
- פלאש שחור-לבן על ה-"6" של כל תיבה.
- כל קאט מקבל "בעיטה" של זום ורעידה, וחזקה יותר על הדאון-ביטים.
- צבע: לפני הדרופ טבעי. מהדרופ והלאה הצבע קריר (צללים כחלחלים), עם חדות, ניגודיות מקומית, זוהר בהיילייטים וצבע חזק. החולצה הצהובה בולטת, והעור לא נשרף.
- הילוך איטי חלק: כל פריים ביניים נוצר ב-AI (RIFE v4.26), כמו "Smooth slow-mo" של CapCut.
- טשטוש תנועה אמיתי: כל פריים הוא ממוצע של עד 32 תת-פריימים לאורך "תריס" של 270°, כך שהזומים והרעידות נמרחים כמו במצלמה.

## איך זה בנוי
- `tools/edit.py`: כל ההחלטות. גריד הביטים, השוטים (קליפ, נקודת עיגון "רגע במקור ↔ ביט", עקומת מהירות וזום) ואירועי האור והמצלמה.
- `tools/render.py`: הרינדור. מיפוי הזמן, דגימת פריימי הביניים (RIFE), המצלמה וטשטוש התנועה, הצבע והפלאשים.
- `tools/rife.py`: ‏RIFE v4.26 עצמאי שרץ על CPU (הארכיטקטורה מ-vs-rife, רישיון MIT).
- `tools/look.py`: הצבע, הזוהר, הנגטיב והשחור-לבן.
- `tools/decode.py`: מפענח את קליפי האייפון לפריימים זקופים.
- `tools/mux.sh`: מלביש את השיר (החל מ-5.576 שנ') עם דעיכה בסוף.
- `tools/build.sh`: בונה הכול מקצה לקצה.

```bash
pip install numpy scipy opencv-python-headless torch
tools/build.sh <תיקיית הקליפים> <קובץ הסאונד> edit.mp4
```
בדיקה מהירה (540×960, בלי AI, עם תוויות של זמן, תיבה ושוט): `python3 tools/render.py video draft.mp4 --draft --label`.
