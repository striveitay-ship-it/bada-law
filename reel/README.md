# bada.law — Reel שיווקי

סרטון Reel אנכי (1080×1920, ‏60fps, ‏32 שניות, לופ מושלם) למשרד עורכי הדין **מיכאל בדלוב ושות'**.
כל הסרטון הוא אלמנט אחד שעובר מורפינג (גודל, רדיוס וצבע) — אייקון → התראה → כרטיס → לוגו → וידאו → כרטיס שירותים → רשימה → נגן → ציטוט → חיוג → כרטיס יצירת קשר → חזרה לאייקון — בלי קאט אחד, כשסמן מבצע כל שינוי בקליקים וגרירות אמיתיים, ומשהו קורה על כל ביט.

**קבצים מוכנים:**
- `out/bada-law-reel.mp4` — הגרסה המלאה: מוזיקה מקורית + סאונד UI.
- `out/bada-law-reel-sfx-only.mp4` — רק צלילי הממשק, בשביל להוסיף שיר מתוך אינסטגרם.
- `out/cover.png`, `out/cover-statement.png`, `out/cover-brand.png` — אפשרויות לתמונת קאבר.
- `out/storyboard.png` — פריים אחד לכל ביט (64 ביטים).

## מותג
- כחול המותג (מכרטיס הסיום בסרטונים של המשרד `#556886`, ובגוון עמוק `#2C3A52`), כסף מוברש של הלוגו, שחור ולבן, רקע אפור חם.
- הלוגו (MB) נבנה מ-4 חלקים על הביטים, ננעל עם ברק מתכתי, מתמלא בוידאו ו"צוללים" דרך ה-B לתוך הצילומים.
- פונט אחד: Heebo. אייקונים: Lucide (ISC), בעובי קו אחיד.

## איך זה בנוי
- `index.html` — כל העיצוב מחושב מהזמן בתוך `REEL.seek(t)`: אין CSS transitions, אין טיימרים ואין מצב שנשמר בין פריימים.
  קפיצים הם פתרון סגור של מתנד מרוסן (תמיד כמעט בלי overshoot); ערך שמשנה יעד כמה פעמים הוא סכום של קפיץ לכל שינוי, וכל שינוי נספר גם מהלופ הקודם — כך הפריים האחרון זהה לראשון, כולל מהירות הסמן.
  שני קצוות אינדיקטור הטאבים רוכבים על קפיצים שונים (הקצה המוביל נמתח קדימה). גרירות הן מניפולציה ישירה: בזמן שהסמן לחוץ הערך מחושב ממיקומו, ובשחרור הוא קופץ חזרה ממקום שבו היה.
- `tools/render.mjs` — רינדור ב-Playwright: ‏8 תת-פריימים לכל פריים (24 בצלילה), ממוזגים ב-ffmpeg ‏tmix לטשטוש תנועה ב-60fps.
- `tools/audio.py` — הפסקול מולחן ומסונתז כאן (F minor, ‏120BPM), כך שאין שאלת זכויות. הסקריפט מודד את גריד הביטים בחזרה (`out/beatgrid.txt`: ‏120.00BPM, הביט הראשון ב-‎+5ms) ומציב כל צליל ממשק לפי השיא הנמדד שלו.
- `tools/clips.sh` — חותך מהסרטונים המקוריים (`assets/source`) את הקטעים בלי הכתוביות הצרובות, עם תיקון צבע עדין.

### בנייה מחדש
```bash
pip install numpy scipy pillow      # + ffmpeg, node עם playwright
tools/clips.sh                      # מחלץ את הפריימים של הצילומים
tools/build.sh /tmp/reel-work       # אירועים → אודיו → וידאו → mp4
```
בדיקה מהירה של פריים לכל ביט: `node tools/render.mjs beats /tmp/beats`.

להחלפת המוזיקה בשיר אחר: כל שיר ב-120BPM יסתנכרן — להתחיל אותו על דאון-ביט ולמקס עם `out/sfx.wav`.
