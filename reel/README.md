# bada.law — Reel שיווקי

סרטון Reel אנכי (1080×1920, ‏43 שניות, לופ מושלם) למשרד עורכי הדין **מיכאל בדלוב ושות'**.
כל הסרטון הוא אלמנט אחד שעובר מורפינג (גודל, רדיוס וצבע) — אייקון → התראה → כרטיס → לוגו → וידאו → כרטיס שירותים → רשימה → נגן → ציטוט → חיוג → כרטיס יצירת קשר → חזרה לאייקון — בלי קאט אחד, כשסמן מבצע כל שינוי בקליקים וגרירות אמיתיים, ומשהו קורה על כל ביט.

**קבצים מוכנים:**
- `out/bada-law-reel.mp4` — הגרסה הראשית: 30fps, ‏H.264 Main — נפתח בכל טלפון ונגן. מוזיקה מקורית + סאונד UI.
- `out/bada-law-reel-60fps.mp4` — אותו דבר ב-60fps.
- `out/bada-law-reel-sfx-only.mp4` — רק צלילי הממשק, בשביל להוסיף שיר מתוך אינסטגרם.
- `out/cover.png`, `out/cover-statement.png`, `out/cover-brand.png` — אפשרויות לתמונת קאבר.
- `out/storyboard.png` — פריים אחד לכל ביט (72 ביטים).

## מותג
- כחול המותג (מכרטיס הסיום בסרטונים של המשרד `#556886`, ובגוון עמוק `#2C3A52`), כסף מוברש של הלוגו, שחור ולבן, רקע אפור חם.
- הלוגו (MB) נבנה מ-4 חלקים על הביטים, ננעל עם ברק מתכתי, מתמלא בוידאו ו"צוללים" דרך ה-B לתוך הצילומים.
- פונט אחד: Heebo. אייקונים: Lucide (ISC), בעובי קו אחיד.

## סאונד
- הפסקול מולחן ומסונתז כאן (F minor, ‏100BPM), כך שאין שאלת זכויות: גרוב פופ/היפ-הופ, בס 808 עם גלישות, צ'ופים ווקאליים, Rhodes, מלודיית הוק, עצירת טייפ לפני "אתם לא לבד.", דרופ על המסך המלא ודרופ שני על כרטיס יצירת הקשר.
- הצלילים עוקבים אחרי התנועה עצמה: כשגוררים את הנגן אחורה וקדימה הפסקול נגרר איתו (כמו טייפ), לכפתור ההחלקה יש "זיפ" שהגובה שלו עולה עם הכפתור, והמספר המתגלגל מתקתק כל פעם שספרה עוברת.
- צלילי ממשק מכוונים לסולם: הטאבים והוי-ים עולים בטונים של האקורד, חלקי הלוגו הם פגיעות מתכת מכוונות.

## איך זה בנוי
- `index.html` — כל העיצוב מחושב מהזמן בתוך `REEL.seek(t)`: אין CSS transitions, אין טיימרים ואין מצב שנשמר בין פריימים.
  קפיצים הם פתרון סגור של מתנד מרוסן (כמעט בלי overshoot); ערך שמשנה יעד כמה פעמים הוא סכום של קפיץ לכל שינוי, וכל שינוי נספר גם מהלופ הקודם — כך הפריים האחרון זהה לראשון, כולל מהירות הסמן.
  שני קצוות אינדיקטור הטאבים רוכבים על קפיצים שונים (הקצה המוביל נמתח קדימה). גרירות הן מניפולציה ישירה: בזמן שהסמן לחוץ הערך מחושב ממיקומו, ובשחרור הוא קופץ חזרה ממקום שבו היה.
  `REEL.curves()` מייצא את עקומות הגרירה והספרות, והסאונד נבנה מהן.
- `tools/render.mjs` — רינדור ב-Playwright: ‏8 תת-פריימים לכל פריים (24 בצלילה), ממוזגים ב-ffmpeg ‏tmix לטשטוש תנועה ב-60fps.
- `tools/audio.py` — הפסקול והסאונד. מודד את גריד הביטים בחזרה (`out/beatgrid.txt`) ומציב כל צליל ממשק לפי השיא הנמדד שלו.
- `tools/clips.sh` — חותך מהסרטונים המקוריים (`assets/source`) את הקטעים בלי הכתוביות הצרובות, עם תיקון צבע עדין; ההליכה עוברת אינטרפולציית תנועה ל-60fps בשביל הסלואו-מושן.

### בנייה מחדש
```bash
pip install numpy scipy pillow      # + ffmpeg, node עם playwright
tools/clips.sh                      # מחלץ את הפריימים של הצילומים
tools/build.sh /tmp/reel-work       # אירועים → אודיו → וידאו → mp4
tools/extras.sh                     # קאברים + סטוריבורד
```
בדיקה מהירה של פריים לכל ביט: `node tools/render.mjs beats /tmp/beats`.

להחלפת המוזיקה בשיר אחר: כל שיר ב-100BPM יסתנכרן — להתחיל אותו על דאון-ביט ולמקס עם `out/sfx.wav`.
